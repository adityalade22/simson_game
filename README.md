# 🎮 Simon Game

A simple and interactive **Simon Game** built using **HTML, CSS, and JavaScript**.

The game tests your memory and concentration by generating a sequence of colored buttons. Each round, the sequence becomes longer, and you have to remember and repeat the exact pattern.

## 🚀 How to Play

1. Press any key to start the game.
2. The game will flash a colored button.
3. Remember the pattern shown by the game.
4. Click the buttons in the same order.
5. With every correct round, a new color is added to the sequence.
6. If you click the wrong button, the game ends.
7. Try to achieve the highest score possible! 🏆

## ✨ Features

* 🎨 Interactive colored buttons
* 🧠 Memory-based gameplay
* 📈 Increasing difficulty with each level
* ⚡ Instant feedback for correct and incorrect moves
* 🔄 Restart and play again
* 📱 Simple and responsive design

## 🛠️ Technologies Used

* **HTML** – Structure of the game
* **CSS** – Styling and animations
* **JavaScript** – Game logic, sequence generation, user interaction, and event handling
